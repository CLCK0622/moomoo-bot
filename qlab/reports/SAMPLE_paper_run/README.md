# ⚠️ SAMPLE paper run — synthetic fixture (NOT strategy performance)

Committed example of the artifact set the execution engine emits. Generated by:

```bash
python -m qlab.run_paper --mode paper --symbols TSLA NVDA AAPL MSFT AMD \
    --start 2025-01-02 --end 2025-02-28 --seed 7 --out reports/SAMPLE_paper_run
```

The bars are **deterministic synthetic data** (`qlab.synthetic`), so the loop is
reproducible with zero external dependencies. **The PnL here is an artifact of
the generator, not of any real market and not of the strategy** — do not read
`summary.json`'s `+28%` as performance.

Channels:

- `signals.jsonl` — every entry/exit signal + the risk decision (allowed/reason).
- `orders.jsonl` / `fills.jsonl` — submitted orders and simulated fills.
- `equity.jsonl` — end-of-day equity + kill-switch state.
- `heartbeat.jsonl` — once per session here (a live loop emits on a timer).
- `positions.jsonl` — **empty by design**: this is an intraday strategy that
  flattens by EOD, so there are no overnight positions. (Intraday snapshots
  appear if you call `engine.snapshot_positions` mid-session.)
- `broker_events.jsonl` / `errors.jsonl` — empty in clean paper mode.

For a real paper-account run use `--mode opend_paper` on a host with an OpenD
gateway (see `../../README.md`).
