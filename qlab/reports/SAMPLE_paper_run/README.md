# ⚠️ SAMPLE paper run — synthetic fixture (NOT strategy performance)

Committed example of the artifact set the execution engine emits. Generated by:

```bash
python -m qlab.run_paper --mode paper --symbols TSLA NVDA AAPL MSFT AMD \
    --start 2025-01-02 --end 2025-01-10 --seed 7 --out reports/SAMPLE_paper_run
```

(7 trading days — a short window is used so the per-bar files stay
review-sized; production runs span months at the same 1m granularity.)

The bars are **deterministic synthetic data** (`qlab.synthetic`), so the loop is
reproducible with zero external dependencies. **The PnL here is an artifact of
the generator, not of any real market and not of the strategy** — do not read it
as performance.

Channels:

- `signals.jsonl` — every entry/exit signal + the risk decision (allowed/reason).
- `orders.jsonl` / `fills.jsonl` — submitted orders and simulated fills.
- `equity.jsonl` — **per bar (1m), mark-to-market**: one row per minute with
  `equity`, `intraday_pnl`, `open_positions`, `peak_equity`, `kill_switch`. This
  is the 1m equity curve 户部 needs to recompute 1m max-drawdown independently.
- `positions.jsonl` — **per bar (1m)** snapshot of every open position
  (`qty`, `entry_price`, `last_price`, `unrealized`). Rows appear only while a
  position is held; this intraday strategy is flat at EOD, so end-of-day minutes
  have no position rows (and `equity.jsonl` shows `open_positions: 0` there).
- `heartbeat.jsonl` — once per session here (a live loop emits on a wall clock).
- `broker_events.jsonl` / `errors.jsonl` — empty in clean paper mode.

For a real paper-account run use `--mode opend_paper` on a host with an OpenD
gateway (see `../../README.md`).
