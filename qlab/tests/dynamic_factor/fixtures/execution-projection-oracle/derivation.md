CF01 是原规则下的完整合成投影输入及手工答案，专用于比较器资格核验，不是市场取数、真实 B/N/账户回执或已运行 planner 的产物。

可信边界在比较器的发布方：本文件、完整输入、原期望字节和 suite-manifest 的 SHA 随规范发布，独审须先核对这些字节。DUT 不能提供/替换 manifest、重算期望答案或取得 oracle 读取权限。测试替身为比较器检错演示而取得字节，不因此充当真实 DUT。以后真实共享 planner 必须只收输入及准许的输入组件；oracle 留在宿主比较器，不下放。

输入完备性针对 draft.1 已列的“投影函数逻辑输入”，不是把全部原始252日行情/当前池传给投影器。包中逐份封存前收账本、锁定信号/权重、资格、执行价/ADV、费用参数及合成来源说明，完整 input 把这些值和原件 SHA 一起绑定。全部 U64 身份、零/非零库存、年龄/冷却、现金、权益/应收、峰值/latch、s/T、目标、分数与可信费用来源均明确，无占位 hash 和必要 null。上游资格/信号是受控合成 provider 的固定输入；不以输入自己写一个 verified=true 冒充真实来源核收。CF01 的 GE50/B 数据只在隔离单元夹具内成立，生产闸不接受。
