## 一、seed 名义化（工部 2026-08-08 第二节裁定）

**必须原样写进每份报告**（代码里由 `qlab/qlab/llm_paper/reporting.py::seed_semantics()` 逐轮落进
round JSON 的 `seed_semantics` 字段，不靠人记得写）：

> `temperature=0`，**seed 为名义值、不产生离散**；离散度由 **2 个 prompt 变体**承担；
> `seed_distribution` 的 **25% 分位在此配置下等于较差的那个变体**。

**不得声称**（`MUST_NOT_CLAIM`）：

- ❌「seed 稳健性通过 / seed-robust」
- ❌「跨 seed 结果稳定」——`temperature=0` 下相同不叫稳定，叫同一次计算
- ❌「下四分位体现了 seed 敏感性」——它体现的是**较差的 prompt 变体**

### 为什么不改 `temperature`（裁定理由，我复验通过）

我原先提的顾虑是「5 个相同值的下四分位就是它本身，护栏显示很稳却没测到东西」。**机制上不成立**：
10 个值里较差那个占 5 个，`np.quantile(v, 0.25)` 的插值位置 `0.25×(10−1)=2.25` 落在排序后第 3、4 个之间，
两者都还是较差那个 ⇒ **下四分位恰等于较差变体**，自然退化成「取较差的 prompt 变体」，**保守方向、不是空壳**。

我用**真** `seed_distribution()` 逐条复算过（不是纸上推导）：

| 变体 A / B | 25% 分位 | = min ? |
|--|--|--|
| 0.40 / 0.10 | 0.100 | ✓ |
| 0.10 / 0.40 | 0.100 | ✓ |
| 0.00 / −0.20 | −0.200 | ✓ |

**边界（这条也必须报，否则口径将来会悄悄失真）**：等式要求较差变体占 **≥ 4/10**；本轨冻结的 5/5
等分网格结构性满足。实测占 3/10 时为 **0.175 ≠ min** ⇒ **一旦变体数被改动，本口径立即失效**。
`reporting.quantile_caliber()` 每轮把这张边界扫描表算进 round JSON，所以口径不会「继续声称一个已不成立的性质」。

叠加 DSR 按冻结网格 **N=10 > 有效 2** 计 ⇒ 多重检验 haircut 偏严。**两处都朝严的一侧。**

另两条不改的理由：`temperature=0` 的**可复现性本身是审计资产**（任何人重跑得到同一批决策，
对「唯一验收证据」比人造离散度值钱）；提温度要动冻结 `signal_params` ⇒ 第 4 次重冻，
换来的是往证据里主动加噪。

## 二、模型漂移（工部 2026-08-08 第三节）— 比 seed 更要紧

`temperature=0` 只是**近似**确定性：供应商可在同名模型后换权重，批处理与浮点也带非确定性。
本轨按年计，**中途模型被换掉 = 实验对象在实验中间变了**，而净值序列不会有任何提示。

实现 `qlab/qlab/llm_paper/determinism.py` + 探针 `qlab/llm_paper_gold_probe.json`：每轮决策附带跑一次
固定输入的模型调用，输出与冻结基线**逐字**比对。

| 结果 | 状态 | 报告处置 |
|--|--|--|
| 逐字相同 | `determinism_ok` | 记一条；并可声明「seed 名义化的前提本轮实测仍成立」 |
| 不同 | **`model_drift_detected`** | 落 ALERT 文件 + 立刻回报工部；`seed_semantics` **自动翻成 `nominal_assumption_broken`**；需判定证据期是否重新起算 |
| 无基线 | `baseline_established` | **本轮什么都没验证到**，报告不得写成通过 |
| 探针被改过 | **`probe_input_changed`** | fail-closed，本轮不起跑 |

**「seed 何时从名义变成实际」由数据说**：漂移一旦检出，同 seed 不再保证同输出，
`effective_distinct_outputs` 置 `null`，之前的净值段与之后不是同一个实验对象。

### 两条如实的边界

1. **抓不了主动造假**：本轨决策者是 agent 自己，没有可编程 LLM 端点，探针输出由调用方传入 ⇒
   不诚实的调用方可以回传基线伪造「一致」。本护栏抓的是**诚实调用方遇到的无声漂移**。
   补偿：探针输出与其 sha256 **逐轮原样写进 round JSON**，都察院可拿仓内基线独立复核。
2. **可能误报**：长输出遇批处理/浮点非确定性会误报。方向安全（误报只升级上报、不静默放过）；
   故探针输出契约刻意全枚举 + 定点数值、不含散文。误报与真漂移看 `diff_preview` 由人判定，代码不猜。
