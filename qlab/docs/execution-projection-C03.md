`qlab.dynamic_factor.execution_projection.project` is the sole normal integer
projection. Candidate and all four reference roles use this function and C06's
`RiskBook.required_m`; there is no reference quantity or risk copy. C13 will
connect the existing candidate orchestration. The three startup opens keep their
separate frozen rule. C04 accounting and C07 returns are not produced here.

```python
project(inputs, *, risk_book, risk_signal, execution_binding,
        expected_input_sha256, expected_snapshot_sha256,
        expected_signal_sha256) -> dict
project_bytes(inputs, *, risk_book, risk_signal, execution_binding,
              expected_input_sha256, expected_snapshot_sha256,
              expected_signal_sha256) -> bytes
```

Every keyword is required. `risk_book` must be the actual shared C06 object;
hashes are host capabilities supplied after reception, not wire claims. Missing,
drifted or draft EXEC-CLOSURE bindings fail. The binding is the unique formal
`7677b123fa2fe573343fad3fe3f43887c5f5d2c0fd7c12d9a1de8bc625162e1b`;
the separate C06 clock and M-01 interpretation remain in force. Actual source,
permissions, raw-open executability and timing must still pass C09. A digest
alone is not source acceptance. Quoting does not execute or certify anything.

The logical input has the publisher's ten named components: `schema`,
`fixture_id` (an identity label, not authority), `economic_semantics_sha256`,
`close_state`, `eligibility`, `execution_open`, `fee_parameters`, `locked_signal`,
`source_component_sha256`, `source_declaration`. Root injection/extra keys and
nonfinite values fail. The sealed counterfactual schema is confined to a
synthetic C06 guard. Normal `EVO884.ProjectorInput/v1` also requires explicit
`execution_open.cash_availability`: `research_immediate` is confined to an
independent training book; `accepted_actual` requires the host-bound mapping
`available_sale_proceeds`. Missing sales availability is unknown. Unspendable
proceeds remain in quoted NAV and never fund buys. This is a feasibility quote,
not an actual fill, settlement or account receipt.

Previous-close inventory/cash/NAV/age/origin/rights/dates must match the immutable
C06 snapshot. B checks precede numeric consumption; quantity state is recomputed
from all named facts. UNKNOWN refuses; LT50 retains the date, original state and
computable M, with P=M and an explicit reason. Known nonzero rights need C04's

context; missing S2 never becomes an empty pool. C09 must establish that context's
authority. Caller weight claims are compared to the internally generated targets.

The closed return schema is `schemas/execution_projection.schema.json`. It has
only `input_sha256/NAV_anchor/M/P/net_orders/reasons/trace`, as frozen D12 requires.
