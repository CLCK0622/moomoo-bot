preparation, owned read facts, P4/P7 publication bindings and isolated replay.
It does not issue a source permission, reconcile N, consume a budget or open L0.

The diagnostic None/None path retains its original roots. Formal roots use
`-BR1`; they carry the exact canonical identity returned by the shared checker.
The native capability stays on the owning object, never in JSON or a hash-keyed
capability registry. Receptions recheck the original host inputs and the fixed A.

The parent passes only an expected identity, A bytes and guard scope outside
stdin. The child must reload the same existing A through its local original
trusted host, or receive a native context explicitly from that host. It checks
before installing the numeric reader or replaying any fact program. The original
host adapter is still unavailable on an unprovisioned child: raw A bytes alone
fail with `B.release_context_trust_binding_missing`; there is no wire constructor,
environment override, synthetic fallback or new host implementation in B04.

binding. A formal sidecar requires the actor's existing three-proof packet,
validated by reference_noncash with the same context; its proof identities and
P4/P7 each carry that publication identity. These are mechanism evidence, never
an actual SRC/AUTH reception, complete production N or runtime permission.
